# Enfermería con Hafsa · MCQ

Personal study app (installable PWA) with nursing multiple-choice questions.

- `src/index.html` — the app and all questions (edit here)
- `build.sh` — wraps `src/index.html` into the installable `index.html`
- `manifest.webmanifest`, `sw.js`, icons — install + offline support

Questions are written in our own words for personal study.
